# Accelerator Metering and Billing

Alauda AI integrates with ACP Cost Management and its accelerator products to make accelerator usage available for metering and billing. The applicable resource type depends on the device option and allocation mode:

- Whole GPU
- Whole NPU
- HAMi Virtual GPU

Cost Management provides the cost models, metrics, pricing, and chargeback configuration for these resources:

| HAMi Virtual GPU | <ExternalSiteLink name="costmanagement" href="/howto/gpu/vgpu_cost_model.html" children="HAMi Virtual GPU cost model" /> |
| Whole NPU | <ExternalSiteLink name="costmanagement" href="/howto/gpu/npu_cost_model.html" children="Whole NPU cost model" /> |
