# Release Notes

## Alauda AI Platform 2.10.0 (Fast)

Alauda AI Platform 2.10.0 is a Fast release. These notes summarize the major platform, model-serving, training, and MLOps changes introduced since Alauda AI Platform 2.9.

### **Upgrade Support**

To be documented.

### **Changes from Alauda AI Platform 2.9**

- **Agent-related components moved to Alauda Agent Platform:** Dify, Alauda Build of MCP Lifecycle Operator, Kagenti, and Alauda Build of Llama Stack are removed from Alauda AI Platform starting from this release; they are no longer installed or managed by `AmlCluster`, and their deployment and usage guides have been removed from the Alauda AI Platform documentation. Agent-related capabilities have moved to the separate Alauda Agent Platform product.
