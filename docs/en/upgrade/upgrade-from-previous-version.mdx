# Upgrade Support

:::warning
**Alauda AI Platform 2.9.0 Fast does not support upgrades from any previous release, including 2.8.** Deploy 2.9.0 Fast as a new installation; do not apply upgrade or migration procedures from earlier releases to an existing environment.
:::

For a new deployment, follow [Install Alauda AI Platform](../installation/ai-cluster.mdx) and check the [supported configurations](../plan/supported_configurations.md).

For the historical 2.3-to-2.8 upgrade procedure, consult the Alauda AI Platform 2.8 documentation. That procedure does not apply to 2.9.0 Fast.
