# Alauda Build of Llama Stack (Deprecated)

**Alauda Build of Llama Stack is deprecated in Alauda AI Platform 2.9 and is not recommended for use.** The `AmlCluster` no longer manages the `llamaStack` component.

Consider [Ogx](https://github.com/ogx-ai/ogx) as an alternative. This recommendation does not imply that Ogx is installed or managed automatically by `AmlCluster`.

The Llama Stack navigation entry is retained for reference. Its deployment, feature, and quick-start guides have been removed from this documentation.
