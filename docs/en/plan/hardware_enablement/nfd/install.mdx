# Install Node Feature Discovery

## Supported configuration

The `v0.20.1-1` release supports ACP v4.1 - v4.4 with amd64 and arm64
packages. It is delivered as the **nfd-operator** Operator Bundle.

## Install the Operator Bundle

1. Upload the `nfd-operator` package through the platform's package upload
   workflow.
2. In **Administrator > Marketplace > OperatorHub**, select **Alauda Build of
   Node Feature Discovery** and install version `v0.20.1-1`.
3. Wait for the CSV `nfd-operator.v0.20.1-1` to reach **Succeeded**.

Installing the Operator does not start NFD on nodes. Create a
`NodeFeatureDiscovery` custom resource after the CSV is ready:

```yaml
apiVersion: nfd.k8s-sigs.io/v1alpha1
kind: NodeFeatureDiscovery
metadata:
  name: nfd
  namespace: node-feature-discovery
spec: {}
```

```bash
kubectl apply -f nfd.yaml
```

## Verify the installation

Check the CR condition and workloads:

```bash
kubectl -n node-feature-discovery get nodefeaturediscovery nfd \
  -o jsonpath='{.status.conditions}'
kubectl -n node-feature-discovery get deployment,daemonset
```

The CR should report `Deployed=True`. The operator, master, garbage collector,
and worker workloads should be ready.

Check that NFD has published labels:

```bash
kubectl get nodefeatures.nfd.k8s-sigs.io --all-namespaces
kubectl get nodes -o json | jq -r '.items[].metadata.labels | keys[]' \
  | grep '^feature.node.kubernetes.io/' | sort -u
```

## Migration from the old Cluster Plugin

The old `node-feature-discovery` Cluster Plugin and `nfd-operator` are separate
delivery forms. Uninstall the old Cluster Plugin and allow its cleanup to
finish before installing the Operator Bundle. Do not install both forms in the
same cluster.
