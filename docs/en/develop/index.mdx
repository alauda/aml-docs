# Develop

This chapter is for data scientists and application developers. It covers workbenches and Kubeflow notebooks, connections, pipeline orchestration, the model registry, experiment tracking, and distributed computing.

The components this chapter relies on are listed under Components below. Agentic MLOps content additionally uses [Envoy AI Gateway](../deploy/components/envoy_ai_gateway/index.mdx) from the Deploy chapter, and uploading a trained model to the model repository is covered in [Upload Models Using Notebook](../deploy/model_management/upload_models_using_notebook.mdx).
