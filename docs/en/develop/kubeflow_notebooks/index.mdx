# Kubeflow Notebooks

Notebook servers, volumes, and TensorBoards from the Kubeflow central dashboard.

Kubeflow Notebooks is an **alternative** to [Workbench](../workbench/index.mdx), not a
part of it. Workbench is the integrated experience on Alauda AI; use Kubeflow Notebooks
when you want the lightweight upstream setup or a feature only the upstream project has.
These pages require the [Kubeflow operators](../components/kubeflow/install.mdx).
