# Evidently release notes

This page records changes to the Evidently chart as published by Alauda. For
upstream SDK and feature details, see the [Evidently documentation](https://docs.evidentlyai.com/).

## v0.7.14-3

- Published the corrected chart and release materials for the Evidently UI.
- The chart is validated for the supported x86_64 and arm64 deployment paths.
- No application feature change is included in this maintenance release.
- Review the release package's security and compatibility reports before
  production rollout.

## Upgrade notes

Upgrade using [Upgrade Evidently](./upgrade). Back up persistent project data
before upgrading from an earlier chart version.
