# Pipelines

Create a pipeline server, build and run Kubeflow Pipelines, and trigger them from Alauda DevOps.

<Overview />

## Notebook guides

- [Configure Elyra Runtime and Runtime Images for Air-Gapped KFP](https://github.com/alauda/aml-docs/tree/master/docs/en/develop/pipelines/assets/elyra-runtime-configuration.ipynb) - create the Elyra KFP Runtime and selectable Runtime Image metadata from a JupyterLab Workbench.
- [Run Kubeflow Pipelines from JupyterLab with Elyra](https://github.com/alauda/aml-docs/tree/master/docs/en/develop/pipelines/run-kubeflow-pipelines-with-elyra.ipynb) - build and submit a two-notebook visual pipeline after completing the runtime configuration notebook.
- [Compile and Run the Ray Data RAG Pipeline](https://github.com/alauda/aml-docs/tree/master/docs/en/develop/pipelines/run-ray-data-pipelines.ipynb) - compile `parse_and_chunk` and `rag_multistep_pipeline` from the `pipelines-components` mirror.

Keep the pipeline notebook and its companion `assets/elyra-runtime-configuration.ipynb` together when downloading them for an air-gapped Workbench.
