# Run MPI Training with Kubeflow Trainer v2

This solution shows how to an OpenMPI workload using Trainer v2 from an Alauda AI Workbench. The runnable notebook is available at [`run-mpi-training-with-trainer-v2.ipynb`](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/notebooks/run-mpi-training-with-trainer-v2.ipynb).

## Run on NVIDIA GPU

Create a Workbench with a CUDA image, upload the notebook, set the namespace and storage parameters in the first cell, and run the cells in order.

## Run on Ascend NPU

Use a CANN Workbench and replace CUDA-specific images and resource keys with the matching Ascend runtime and `huawei.com/Ascend910B`. Pipeline, tracking, and evaluation steps can remain unchanged; training code must use `torch_npu`, LlamaFactory, or MindSpeed.
