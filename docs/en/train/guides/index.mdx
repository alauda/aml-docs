# Training Guides

End-to-end recipes for training and fine-tuning models on Alauda AI.

## Supported features and algorithms

This table summarizes the algorithms and workloads covered by the current guides. Accelerator scope describes the documented path; it is not a general compatibility guarantee for every model or device.

| Feature | Documented algorithms or workloads | Accelerator scope | Solution and guide |
|---|---|---|---|
| LLM supervised fine-tuning | Full-parameter SFT with MindSpeed-LLM or MindSpore; LLaMA-Factory SFT runtime | Ascend NPU full-parameter SFT has runnable Workbench and Trainer v2 recipes. The LLaMA-Factory CANN image is listed as a runtime; its NPU LoRA workflow is not covered end to end. | [Fine-tune and Pretrain on Ascend NPU](./fine-tune-and-pretrain-llms-on-ascend-npu.mdx); [Fine-Tuning with Kubeflow Trainer v2](./fine-tune-with-trainer-v2.mdx); [Training Runtime Images](./training-runtimes.mdx) |
| LLM continued pretraining | CPT on raw text; MindSpeed-LLM pretraining | Training Hub CPT is documented for NVIDIA GPU. Ascend has a runnable MindSpeed-LLM pretraining recipe. | [Training Hub fine-tuning](./training-hub-fine-tuning.mdx); [Fine-tune and Pretrain on Ascend NPU](./fine-tune-and-pretrain-llms-on-ascend-npu.mdx) |
| Parameter-efficient or continual fine-tuning | LoRA, QLoRA, OSFT | Training Hub guides target NVIDIA GPU. Ascend has a LLaMA-Factory CANN runtime listing, but no current end-to-end NPU LoRA guide. The current guide states bitsandbytes NF4 QLoRA is unavailable on Ascend. | [Training Hub fine-tuning](./training-hub-fine-tuning.mdx); [Training Runtime Images](./training-runtimes.mdx) |
| LLM preference and reinforcement learning | DPO runtime capability; GRPO / RLVR with `lora_grpo` and `verl` | Documented for NVIDIA GPU. No Ascend training recipe is currently documented. | [Training Hub fine-tuning](./training-hub-fine-tuning.mdx); [RL with verifiable rewards](./training-hub-rl-verifiable-rewards.mdx) |
| Machine-learning model training | YOLOv5 object-detection fine-tuning | NVIDIA GPU training is documented. The YOLOv5 Ascend paths cover inference after GPU training, not NPU training. | [Train, Fine-Tune, and Deploy YOLOv5](./yolov5-training-and-triton-deployment.mdx); [Train on GPU and Run Inference on NPU](./train-on-gpu-infer-on-npu.mdx) |
| Distributed training | PyTorch DDP with JobSet; MPI with Trainer v2; MindSpeed-LLM SFT | DDP and MPI have runnable Kubernetes examples. The Ascend Trainer v2 example validates a single-node MindSpeed-LLM job; multi-node NPU guidance is limited to cluster-specific prerequisites. | [Distributed PyTorch with JobSet](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/run-distributed-training-with-jobset.ipynb); [MPI Training with Trainer v2](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/run-mpi-training-with-trainer-v2.ipynb); [Fine-Tuning with Kubeflow Trainer v2](./fine-tune-with-trainer-v2.mdx) |
| Training scheduling and accelerator quota | Kueue queues, quota, preemption; GPU slicing with DRA | GPU scheduling and Ascend NPU quota are documented. | [Preemptible TrainJobs with Kueue](./preemptible-trainjobs-with-kueue.mdx); [GPU Slicing with DRA](./gpu-slicing-with-dra.mdx); [Manage Ascend NPU quota with Kueue](../quota_scheduling/npu_quota.mdx) |

## Pick a path

| When you want… | Use | Guide |
|---|---|---|
| Fine-tune or train on GPU and serve a compatible model on Ascend NPU | Cross-accelerator workflow index | [Train on GPU and Run Inference on NPU](./train-on-gpu-infer-on-npu.mdx) |
| Fine-tune a YOLOv5 object-detection model and deploy it with Triton | Kubeflow Trainer v2 + Triton Inference Server | [Train, Fine-Tune, and Deploy YOLOv5](./yolov5-training-and-triton-deployment.mdx) |
| Reusable templates, repeatable runs, optional Kueue quotas | Kubeflow Trainer v2 + LlamaFactory | [Fine-Tuning with Kubeflow Trainer v2](./fine-tune-with-trainer-v2.mdx) |
| Survive crashes, preemption, or a pause without losing hours of training | Checkpoint PVC + `resume_from_checkpoint` + `maxRestarts` | [Checkpointing and Resuming TrainJobs](./checkpointing-and-resuming.mdx) |
| Survive crashes, preemption, or a resubmit of a KubeRay training job | Checkpoint PVC + Ray Train `storage_path` + `TorchTrainer.restore` | [Checkpointing and Resuming RayJobs](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/kuberay-checkpointing-and-resuming.ipynb) |
| Mix training with online inference, yield GPU back on demand | Kueue cohort + preemption + checkpoint resume | [Preemptible TrainJobs with Kueue](./preemptible-trainjobs-with-kueue.mdx) |
| Run a fine-tune on a *slice* of a GPU instead of a whole card | Dynamic Resource Allocation (DRA) MIG slice + Trainer v2 | [GPU Slicing with Dynamic Resource Allocation (DRA)](./gpu-slicing-with-dra.mdx) |
| A curated set of `TrainingRuntime` images (CUDA / CANN) | Trainer v2 runtime catalog | [Training Runtime Images](./training-runtimes.mdx) |
| One-shot quick start of distributed PyTorch on Trainer v2 | `ClusterTrainingRuntime` + MNIST | [Kubeflow Trainer Quick Start](./kubeflow-trainer-quick-start.md) |
| Run a two-node PyTorch DDP job directly with Kubernetes JobSet | Indexed Job + stable pod DNS + `torchrun` | [Run Distributed PyTorch Training with JobSet](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/run-distributed-training-with-jobset.ipynb) |
| Run an OpenMPI workload on Trainer v2 | MPI-enabled `TrainingRuntime` + `TrainJob` | [Run MPI Training with Kubeflow Trainer v2](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/run-mpi-training-with-trainer-v2.ipynb) |
| Production SFT / OSFT with automatic memory management | `training_hub` | [Fine-tuning LLMs with Training Hub](./training-hub-fine-tuning.mdx) |
| Reinforcement learning from programmatically verifiable rewards | Training Hub `lora_grpo` + `verl` | [Run RL with verifiable rewards using Training Hub](./training-hub-rl-verifiable-rewards.mdx) |
| Interactive exploration, custom scripts, VolcanoJob submission | Workbench Notebook | [Fine-tuning LLMs using Workbench](./fine-tuning-using-notebooks.mdx) |
| Turn PDFs into SFT JSONL from a Workbench | Docling + SDG Hub + OpenAI-compatible teacher | [Prepare Fine-Tuning Data with Docling and SDG Hub](./prepare-finetune-data-with-docling-and-sdg.mdx) |
| Full-parameter SFT / pretraining on Ascend NPU | Workbench `PyTorch CANN` / `MindSpore CANN` | [Fine-tune and Pretrain on Ascend NPU](./fine-tune-and-pretrain-llms-on-ascend-npu.mdx) |
| Track a KFP run's parameters and metrics in MLflow | KFP component + MLflow SDK | [Kubeflow Pipeline + MLflow Integration](../../develop/experiment_tracking/pipelines-mlflow-integration.mdx) |
| Build features offline, materialize them online, and serve a model with Feast | Feast Operator + KServe | [Feast Offline-to-Online Inference](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/feast-offline-to-online-inference.ipynb) |
| Run Feast's Ray offline store on a KubeRay cluster | Feast Ray offline store + KubeRay Operator | [Feast with Ray Offline Store](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/feast-with-ray-offline-store.ipynb) |
| Run a distributed training job on KubeRay and compare runs in MLflow | KubeRay RayJob + Ray Train + MLflow | [Train on KubeRay and Track Experiments with MLflow](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/kuberay-training-with-mlflow.ipynb) |
| Submit KubeRay training jobs through Kueue and scale workers on demand | Kueue admission + Ray Autoscaler v2 | [KubeRay Training with Kueue and Autoscaling](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/kuberay-training-with-kueue-autoscaling.ipynb) |
| Train tabular or time-series models with reusable AutoGluon assets | Managed KFP pipelines or composable components | [Use Reusable Kubeflow Pipeline Components](../../develop/pipelines/reusable-pipeline-components.mdx) |
| Use KFP caching, parallel loops, and persistent typed artifacts | KFP 2.16.1 execution mechanisms | [Kubeflow Pipelines Execution and Storage Behavior](../../develop/pipelines/kfp-execution-and-storage.mdx) |
| Daily fine-tune → evaluate → compare loop with MLflow + TrustyAI | KFP Recurring Run + MLflow Model Registry + `LMEvalJob` | [Daily Fine-Tuning Pipeline with MLflow and TrustyAI](./fine-tuning-pipeline-with-mlflow-trustyai.mdx) |
| Parse thousands of PDFs with Ray Data and optional Milvus ingest | KFP `parse_and_chunk` RayJob from `pipelines-components` | [Run Ray Data Pipelines from pipelines-components](./run-ray-data-pipelines.mdx) |
| Search RAG chunking, embeddings, and retrieval settings for a document corpus | KFP AutoRAG pipelines + OGX (Llama Stack) | [Optimize a RAG Application with AutoRAG Pipelines](https://github.com/alauda/aml-docs/tree/master/docs/en/train/guides/optimize-rag-with-autorag.ipynb) |
