:::note
The TrainingHub runtime currently supports NVIDIA CUDA only. An NPU solution must use an Ascend-compatible training runtime and implement the post-training algorithm with LlamaFactory, MindSpeed/MindSpeed-LLM, or `transformers` with `torch_npu`. Do not select a TrainingHub notebook for an NPU Workbench.
:::

For checkpointing, preemption, GPU slicing, and runtime image details, see [Checkpointing and resuming](./checkpointing-and-resuming.mdx), [Preemptible TrainJobs](./preemptible-trainjobs-with-kueue.mdx), [GPU slicing](./gpu-slicing-with-dra.mdx), and [Training runtime images](./training-runtimes.mdx).
