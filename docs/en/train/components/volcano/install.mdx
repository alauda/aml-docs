# Install Volcano

## Download the Operator package

:::info

The `volcano-operator` package can be retrieved from Customer Portal.

Please contact Consumer Support for more information.

:::

## Upload the Operator package

Download the `volcano-operator` package, then upload it following [Upload Packages](../../../installation/package-upload.mdx).

## Install Volcano

1. Go to `Administrator` -> `Marketplace` -> `OperatorHub`, switch to the target cluster, and install `volcano-operator`.
   :::info
   **Note:** Keep the default parameters unless you have a specific configuration requirement.
   :::
2. Confirm that the Operator status is `Installed` and the Volcano pods are running.

For an existing installation, see [Upgrade Volcano](./upgrade).

## Uninstall Volcano

Before removing `volcano-operator`, delete any `VolcanoJob`, `PodGroup`, `Queue`, and `JobFlow` resources that should not be retained. Uninstall does not remove these resources.
