# Katib AutoML

Katib runs Kubernetes-native hyperparameter tuning experiments. The Alauda build is installed as an OLM operator and supports the Katib `Experiment`, `Suggestion`, and `Trial` APIs.

Use the operator in a project namespace with access to the platform-provided MySQL service. Training workloads run as Kubernetes Jobs or supported Kubeflow training resources.
