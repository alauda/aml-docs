# Monitor

This chapter covers logging and tracing for inference services, resource monitoring and dashboards, and model bias and drift monitoring. Logging and resource monitoring serve inference service users, while configuring monitoring dashboards requires the administrator view.

Bias and drift monitoring is provided by [TrustyAI](../evaluate_safety/components/trustyai/index.mdx) from the Evaluate & Safety chapter.
